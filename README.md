### Hashtable and linked lists

# RUNNING THE TESTS:
    Hash_table: 
        To run the tests, you need to first compile the files, you do this by typing: make hash_tests and then
        ./hash_test. To check if there are any memory leaks you can write make memtest_hash.

    Linked_list: 
        To run the tests you first compile them with "make tests" and then type "./linked_list_tests".
        To check for memory leaks, you type "make memtest".
    
    Linked_list_iterator:
        Type "make itertest" to compile the code and then type "iter_test" to run the tests.
        To check for memory leaks, write "make memtest_iter"
